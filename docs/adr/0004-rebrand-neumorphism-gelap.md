# Rebrand Neumorphism gelap (Forest + Emerald)

Chrome aplikasi + halaman auth ditulis ulang ke bahasa Neumorphism gelap:
kanvas forest `#141D19`, bayangan ganda (`#0C1210`/`#2A3A34`), font Rubik.
Timbul = aksi/permukaan interaktif, cekung = isi/wadah/aktif. Aksen emerald
dipertahankan sebagai benang brand (termasuk ikon PWA yang sudah dikirim).

**Alasan**: identitas dark-first lama terbaca generik (kartu bergaris generik);
neumorphism memberi identitas taktil yang khas, dengan resep yang sudah
terbukti di template portfolio pemilik (varian gelap `#212121`), diadaptasi ke
forest agar selaras ikon PWA dan makna hijau-uang. Alternatif terang (themesberg)
ditolak untuk sekarang karena membalik seluruh fondasi dark; disiapkan sebagai
fitur susulan di atas token semantik (nol heksa hardcoded adalah syaratnya).

**Konsekuensi**: `DESIGN.md` ditulis ulang total (aturan "tanpa bayangan lunak"
dicabut — bayangan kini bahasa utama); PDF dan halaman klien eksplisit tidak
ikut; prototipe throwaway di branch `prototype/neu` dihapus sebelum merge;
disiplin kontras baru (teks kecil minimal `text-muted`).
